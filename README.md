# Wits & Wagers Online

เกมตอบคำถามตัวเลข + เดิมพัน เล่นกับเพื่อน/ครอบครัว 3-10 คน: **จอทีวีเป็นกระดานเดิมพัน, มือถือเป็นตัวตอบและวางเหรียญ**
(Next.js 14 + Upstash Redis, deploy บน Vercel)

## กติกา
1. ทุกรอบมีคำถามที่คำตอบเป็นตัวเลข (เช่น ภูเขาสูงกี่เมตร, เหตุการณ์เกิดปี พ.ศ. อะไร) ทุกคนพิมพ์คำตอบบนมือถือ
2. ทีวีเรียงคำตอบทุกคนจากน้อยไปมาก เป็นช่องเดิมพัน (คำตอบที่ซ้ำกันรวมเป็นช่องเดียว) พร้อม **ตัวคูณ**: ช่องกลางจ่าย ×2 ยิ่งไกลกลางยิ่งจ่ายสูง (×3, ×4, ×5) และมีช่องพิเศษ **“ต่ำกว่าทุกคำตอบ” จ่าย ×6**
3. ทุกคนวางเดิมพัน **2 เหรียญ** (วางซ้ำช่องเดียวกันได้ วางบนคำตอบของตัวเองได้)
4. เฉลย: คำตอบที่ **ใกล้เฉลยที่สุดโดยไม่เกิน** คือช่องที่ชนะ (ถ้าทุกคำตอบสูงเกิน ช่อง “ต่ำกว่าทุกคำตอบ” ชนะ)
   - เหรียญบนช่องที่ชนะได้แต้ม = ตัวคูณ (ต่อเหรียญ)
   - คนที่ตอบช่องที่ชนะได้โบนัส +3
5. 2 รอบสุดท้ายคะแนนคูณ 2 · เล่นครบรอบ (5/7/10) แต้มรวมสูงสุดชนะ

## ปรับแต่ง
- `lib/config.js` จำนวนเหรียญ ตัวคูณ โบนัส จำนวนรอบ
- `lib/questions.js` ชุดคำถาม (คำถาม, คำตอบ, หน่วย) 61 ข้อ เพิ่มได้เอง

## รัน/ดีพลอย
- Vercel: import repo นี้ แล้วเชื่อม Upstash Redis (Storage) จากนั้น Redeploy · Redis key ขึ้นต้น `ww:`
- รันในเครื่อง: `npm i && npm run dev` · ทดสอบ engine: `node scripts/test.mjs`


## ความปลอดภัย (ล็อกการสร้างห้อง)
ตั้งตัวแปร `FAMILY_PASSCODE` ใน Vercel (Settings → Environment Variables) แล้ว Redeploy ปุ่ม “สร้างห้องใหม่” จะถามรหัสผ่านก่อน (เครื่องที่กรอกถูกจะจำไว้) ส่วนผู้เล่นที่สแกน QR เข้าห้องไม่ต้องใส่อะไร ถ้าไม่ตั้งตัวแปรนี้ จะไม่ล็อก
เว็บตั้งค่า `noindex` ไว้ ไม่ให้ Google เก็บ
